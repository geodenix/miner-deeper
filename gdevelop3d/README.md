# Miner Deeper GDevelop 3D — v0.2

Автоматически собираемая мобильная 3D-версия.

## Что уже работает
- 3D-шахта и камера от третьего лица
- мобильный виртуальный джойстик
- прыжок
- отдельная кнопка **КИРКА**
- рудные 3D-блоки с 3 единицами прочности
- добыча: 3 удара → блок разрушается → +1 руда
- рюкзак 20 единиц
- HUD руды
- 5000 стартовых монет в проектных переменных

Веб-версия автоматически экспортируется GitHub Actions и публикуется в ветку `gh-pages`.
