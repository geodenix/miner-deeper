# Miner Deeper GDevelop 3D v0.1

Первая автоматически подготовленная версия.

Что уже есть:
- мобильный виртуальный джойстик;
- 3D-персонаж на встроенном Cube3D;
- физика 3D-персонажа;
- камера от третьего лица;
- тёмная шахтная сцена;
- стены и препятствия;
- рудные коллектаблы;
- 2 физические толкаемые шахтные ящики;
- стартовые переменные: 5000 монет, уголь, железо, золото, алмазы, рюкзак 20.

Открыть: файл miner-deeper-gdevelop.json в GDevelop.
